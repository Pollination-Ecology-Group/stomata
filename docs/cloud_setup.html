Cloud Storage Setup

Connecting to the CESNET S3 drive with Rclone

ImportantCredentials

Ask the Project Lead for the team access_key_id and secret_access_key before starting. Do not share them via Slack or email — use a secure channel.

Goal: Mount the team’s CESNET S3 bucket as a local folder so you can drag-and-drop microscopy images and retrieve results without a browser.

Step 0 — Install Prerequisites

You need Rclone (the connector) and a FUSE driver (so Rclone can present the bucket as a folder).

  • 🐧 Linux
  • 🪟 Windows
  • 🍎 macOS
sudo apt install rclone fuse3
  1. Download Rclone for Windows, unzip, place rclone.exe in e.g. C:\rclone\, add to PATH.
  2. Download and install WinFsp — required for mounting.
brew install rclone

Then download and install macFUSE.

Note (Apple Silicon): You may need to allow kernel extensions in Recovery Mode for macFUSE. Check if fuse-t works as an alternative on M1/M2/M3.

Step 1 — Configure the Connection

Run the interactive wizard (same on all platforms):

rclone config

Answer the prompts as follows:

Rclone configuration values
Prompt Value
New remote? n
Name cesnet_s3
Storage type Amazon S3 Compliant Storage
Provider Ceph
env_auth false
access_key_id (Team Access Key)
secret_access_key (Team Secret Key)
endpoint https://s3.cl4.du.cesnet.cz
acl private
Save y

Step 2 — Mount the Drive

  • 🐧 Linux
  • 🪟 Windows
  • 🍎 macOS

One-time:

mkdir ~/cesnet_cloud
rclone mount cesnet_s3: ~/cesnet_cloud --vfs-cache-mode writes --daemon

Auto-start on login — open Startup Applications, click Add, and use this command:

rclone mount cesnet_s3: /home/YOUR_USER/cesnet_cloud --vfs-cache-mode writes --daemon

Alternative — Direct S3FS Mount (peg-bucket):

mkdir -p ~/cesnet_new
s3fs peg-bucket ~/cesnet_new -o passwd_file=${HOME}/.passwd-s3fs -o url=https://s3.cl4.du.cesnet.cz -o use_path_request_style -o allow_other -o uid=$(id -u) -o gid=$(id -g)

One-time (PowerShell):

mkdir C:\cesnet_cloud
rclone mount cesnet_s3: C:\cesnet_cloud --vfs-cache-mode writes

Keep this terminal open — closing it disconnects the drive.

Auto-start: Create mount_cesnet.bat with:

@echo off
start /b rclone mount cesnet_s3: Z: --vfs-cache-mode writes --no-console

Place the .bat file in shell:startup (Win + R → type shell:startup).

One-time:

mkdir ~/cesnet_cloud
rclone mount cesnet_s3: ~/cesnet_cloud --vfs-cache-mode writes --daemon

Auto-start: Create mount_cesnet.sh:

#!/bin/bash
rclone mount cesnet_s3: /Users/YOUR_USER/cesnet_cloud --vfs-cache-mode writes --daemon

Make it executable (chmod +x mount_cesnet.sh) and add it in System Settings → General → Login Items.

⚠️ Best Practices

Warning

Don’t edit large files in place. Copy the file to your local desktop first, edit it there, then copy it back. Opening a multi-GB image directly from the cloud drive will be slow.

Tip

Wait for uploads. When you drag a file into cesnet_cloud/, give it a few seconds to finish uploading before shutting down your computer.

If the drive freezes (e.g. internet loss), unmount it:

Platform Command
Linux fusermount -u ~/cesnet_cloud
Windows Ctrl+C in the terminal
macOS umount ~/cesnet_cloud

## ⚠️ Best Practices

::: {.callout-warning}
**Don't edit large files in place.** Copy the file to your local desktop first, edit it there, then copy it back. Opening a multi-GB image directly from the cloud drive will be slow.
:::

::: {.callout-tip}
**Wait for uploads.** When you drag a file into `cesnet_cloud/`, give it a few seconds to finish uploading before shutting down your computer.
:::

**If the drive freezes** (e.g. internet loss), unmount it:

| Platform | Command |
|---|---|
| Linux | `fusermount -u ~/cesnet_cloud` |
| Windows | `Ctrl+C` in the terminal |
| macOS | `umount ~/cesnet_cloud` |
