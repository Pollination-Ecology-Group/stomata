Inference Pipeline

How PSCA processes microscopy images at scale

Overview

PSCA is a containerised batch pipeline that:

  1. Downloads images from CESNET S3 storage
  2. Runs YOLOv11 instance segmentation on each image
  3. Extracts geometric traits from the segmentation masks
  4. Saves results to a CSV and uploads it back to S3

The pipeline runs as a Kubernetes Job — no local GPU required.

Architecture

Step-by-Step

Step 1 — Model Download

If the model is not already cached at MODEL_PATH (/tmp/best.pt by default), it is downloaded from S3 at startup:

if S3_MODEL_KEY and not os.path.exists(MODEL_PATH):
    s3.download_file(S3_BUCKET, S3_MODEL_KEY, MODEL_PATH)

The model key is configured via the S3_MODEL_KEY environment variable.

Step 2 — Image Discovery

The S3 bucket is paginated to find all .jpg / .jpeg / .png files under the configured prefix:

paginator = s3.get_paginator('list_objects_v2')
pages = paginator.paginate(Bucket=S3_BUCKET, Prefix=TILE_PREFIX)

Default prefix: Ostatni/Stomata/extracted/

Step 3 — Parallel Download + Inference

Images are processed in batches of 100 to limit memory usage. Within each batch, images are downloaded concurrently using a 16-worker thread pool:

with concurrent.futures.ThreadPoolExecutor(max_workers=FETCH_WORKERS) as executor:
    futures = [executor.submit(download_image, s3, key) for key in batch_keys]
    for future in concurrent.futures.as_completed(futures):
        key, img = future.result()
        if img is not None:
            res = process_image(model, img, image_name)
Note

YOLO inference itself runs sequentially on the GPU. Only image downloading is parallelised — this hides S3 network latency behind GPU compute time.

Step 4 — Trait Extraction

For each image, process_image() in extract_traits.py:

  1. Runs YOLO inference → gets segmentation masks + class labels
  2. Separates masks into stoma (class 1) and pore (class 0) lists
  3. For each stoma, finds the matching pore (containment check → nearest-neighbour fallback)
  4. Computes the minor axis via cv2.minAreaRect() and shapely intersection
  5. Returns a list of measurement dicts

See the Measurements page for full trait definitions.

Step 5 — Output & Upload

Results are collected into a pandas DataFrame, saved to a local CSV, then uploaded to S3:

S3_OUTPUT_KEY = "Ostatni/Stomata/stomata_traits.csv"

Intermediate saves happen every 1000 images to guard against job interruption.
