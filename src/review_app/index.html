🌿 Stomata Detection QC & Relabeling Studio Guide

How to fastly evaluate detection quality and use the in-app annotation studio for active learning retraining.

🔬 Part 1: Fast Detection Evaluation

Grade model detection quality rapidly with 1-click verdicts (1 High Precision, 2 Minor Error, 3 Poor Outline, 4 False Stoma). Enable Auto-Advance to evaluate 20+ stomata per minute effortlessly. Any poor outlines or false stomata automatically queue into the Relabeling Studio with top priority!

🏷️ Part 2: In-App Relabeling Studio

Eliminates Roboflow completely! Candidates are sorted by Active Learning Priority (cases that will improve the YOLO segmentation model the most first). Drag vertices with E, draw outlines with P, drag quick ellipses with B, mark negatives with N, and save ground truth directly with Space.
